# WarFil — бот клана в Telegram

Показывает атаки в клановой войне, раунды ЛВК и рейды столицы, сам пишет в беседу
о старте, напоминает тем, кто не атаковал, и присылает итоги.

## Запуск на сервере

```bash
git pull
pip install -r requirements.txt
cp .env.example .env      # и заполни токен и доступ к CoC API
pm2 restart wfcocbot      # или: python main.py
```

Затем в Telegram:

1. В беседе клана отправь `/addchat` (если её нет в `/listchats`).
2. `/status` — видно, работает ли каждый монитор, когда был последний успешный
   цикл и какая ошибка, если что-то сломалось. `/check` — прогнать проверку сразу.

## Что присылает бот

| Событие | Когда |
|---|---|
| Соперник найден | начало дня подготовки |
| Война началась | начало боевого дня |
| Напоминание со списком без атак | за 4 часа и за 1 час до конца |
| Итоги войны, лучшие атаки, кто пропустил | после окончания |
| ЛВК: старт раунда с составом, напоминание за 3 часа, итоги раунда | каждый раунд |
| Рейды: старт, напоминание за сутки и за 3 часа, итоги | каждый уикенд |

Каждое событие отправляется один раз — состояние хранится в `data/notify_state.json`.

## Игровые эмодзи

Бот умеет ставить в сообщения и на кнопки кастомные эмодзи из любого пака.
Telegram разрешает это ботам, только если у владельца бота есть **Telegram Premium**;
без него бот автоматически показывает обычные эмодзи.

- `/emojipack https://t.me/addemoji/<имя>` — подтянуть пак, бот сам сопоставит значки
- `/setemoji war ⚔️ star ⭐ capital 🏛️` — вручную (вставь эмодзи из пака)
- `/emoji` — все ключи и текущие значки, `/emojireset` — вернуть обычные
